# Starborn

A mobile-first, portrait science-fiction RPG for Android, with a Windows desktop port and shared Kotlin gameplay runtime.

Start with [the documentation index](docs/README.md) and [the dated implementation snapshot](docs/CURRENT_STATE.md). Current code and assets are the default truth for implemented behavior; older design documents must be reconciled against them.

- Android application: `app/`; shared rules: `gameRuntime/`; desktop application: `desktopApp/`.
- Content: `app/src/main/assets/`; additional world media: `world_assets/src/main/assets/`.
- [Testing](docs/testing/README.md), [Windows builds](docs/desktop/WINDOWS_BUILD.md), [documentation cleanup](docs/DOCUMENTATION_CLEANUP.md).

Old root handoffs now link to preserved historical copies. They are not current task lists or release instructions.
