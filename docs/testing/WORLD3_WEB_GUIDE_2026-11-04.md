# World 3 web playtest guide

Adds World 3 alongside Worlds 1 and 2 in the GitHub Pages reader. The maintained Markdown contains 45 main-route steps derived from the production campaign route and authored room connections, all eleven quest checklists, and references for all seventy rooms. The Upper City transition is explicit; Lens acquisition uses the visible relic interaction.

The reader supports direct World 3 links, saved per-world checklist/position, cross-world search and offline reading. Existing World 1/2 storage keys remain intact. World 3 journal checklists are actionable; mobile world selection accommodates the third button without horizontal overflow.

Local headless Chrome checks pass for direct entry, saved World 3 checklist, World 1 progress/position restoration, World 2 data/search, theme, 320/390 px layouts and offline reload. The World 3 mobile screenshot was visually inspected. Gameplay optional routes and numerical balance are still playtest subjects; this publication is not a completionist gameplay certification.

Publication uses the existing gh-pages branch. The website changes do not require another Android install; Pixel version 1.3.107 build 191 contains the stabilization fixes.
