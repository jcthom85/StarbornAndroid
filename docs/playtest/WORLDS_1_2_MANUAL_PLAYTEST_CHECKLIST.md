# Worlds 1–2 Manual Playtest Checklist

A player-facing review checklist for the current campaign. Use it during one long run or split it into two sessions. This is not a completionist route or a scripted pass/fail test: play naturally, pause when something feels confusing or especially good, and write down what happened.

World 2's current interaction and recovery changes are summarized in [World 2 Refinement Pass](../WORLD2_REFINEMENT_PASS.md). The older [World 1 field guide](walkthroughs/WORLD_1_COMPLETIONIST_WALKTHROUGH.md) and [World 2 field guide](walkthroughs/WORLD_2_COMPLETIONIST_WALKTHROUGH.md) contain route detail, but their old level, reward, and release benchmarks should not be treated as current acceptance criteria.

## Before starting

- [ ] Record device, Android version, game version/build, and whether this is a fresh or existing save.
- [ ] Use the normal player route. Avoid debug shortcuts and instant-win tools unless isolating a specific bug.
- [ ] Keep notes short: room or menu page, what you tried, what you expected, what happened, and a screenshot/video if useful.
- [ ] At major chapter beats, rate **clarity**, **fun**, and **pacing** from 1 (poor) to 5 (strong). Mark "not sure" instead of guessing.
- [ ] If you need to stop, make a normal save and note the room, active quest, and next journal objective.

## Menu and save sweep

Do this once in each world, ideally in rooms with different lighting or background colors.

- [ ] Open Party: check member selection, Attributes, Skills, equipment, and gear comparison.
- [ ] Open Items: check icon filters, item details, effect descriptions, and targeted item use. Cancel target selection and confirm you return to the same item details.
- [ ] Open Tinker: check Workbench, Schematics, and Scrap. Confirm scrap preview matches what you receive if you choose to scrap something.
- [ ] Open Journal: check tracked quest, next objective, optional objectives, and completed entries.
- [ ] Open Map: confirm this tab itself is the full interactive map. Try drag, pinch zoom, zoom buttons, and Recenter. Confirm there is no extra “Open Full Map” step; check Map Legend.
- [ ] Check readability, scrolling, and controls at your usual text size. If practical, repeat a quick menu scan with larger system text or the large-target setting.
- [ ] Use Quick Save and one manual slot. Load the manual save and verify room, party, inventory, equipment, and quest progress.
- [ ] From Settings → Save Data, use **Save & Return to Title** only when ready to leave. Confirm it saves before returning, then load back into the campaign if continuing.
