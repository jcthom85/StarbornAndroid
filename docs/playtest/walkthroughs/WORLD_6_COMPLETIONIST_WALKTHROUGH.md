# World 6 — The Source: completionist route and playtest guide

Updated November 5, 2026 for the repaired Source navigation build and shared exploration controller. This replaces the earlier speculative guide. Coverage means all five main quests and all optional quests on the documented routes; it does not certify every room, build, or incidental interaction.

## Navigation and returns

All 65 World 6 rooms use NSEW swipe exits with immediate opposite-direction returns. There are no diagonal exits. Named memory shortcuts remain optional tapped actions; they supplement walking returns.

- **Zeke:** Campfire → west → Infinite Cubicle → west → Performance Review Loop. Return east/east. Break Room Exit is south of the review loop; its north exit returns to the loop.
- **Gh0st:** Campfire → north → Endless War → north → Order Well. Return south/south. His Kill-Suite and Clean Signal Alcove remain east of Endless War.
- **Orion:** Campfire → east → Blue Ash Circle → east → Silent Shore → east → Tide-Well. Return west/west/west. Answering Chorus is one more step east. The northern branch from Blue Ash Circle remains an optional memory walk with a swipe return.
- **Mines and bridge:** Campfire → south → Echo of the Mines → east → Jed's Echo Bench → east → Manager Patrol Route → east → The Elevator. After evading the Manager, the elevator completes MQ27 and transfers the crew to Memory Bridge. West from the bridge returns to the elevator and the Campfire route.
- **Across the bridge:** build the unfinished bridge after setting all four anchors, then swipe east to Shared Memory Span and east to Singularity Threshold. The threshold's action crosses to Memory Stair after the campfire promise. Its east swipe is available thereafter, with a west return to the span for rest.
- **Ascent:** at Memory Stair, refuse all three revisions and use the memory stair before swiping east. Continue east through World-Fracture Landing, Spire of Thought and Impossible Archive to Memory Defense Arena. Defeat the memory defenders before crossing east into the Center. Westward retreat remains available throughout.
- **Finale:** the Silence Pulpit is three north swipes from the Center, through White Shore and Key Orbit. Return south/south/south. The New World stays east of the Center behind the ending gate until the Final Note completes. Afterward, its west route deliberately revisits the remembered Source; the north street leads toward the Astra shuttle terminal.

The four new forward locks enforce existing objectives, rather than turning return walks into story commitments. They stay open after clearance. Older saves already beyond a lock preserve access without replaying a quest reward. Rest on Shared Memory Span remains reachable before and between the final battles.

## Main route

1. At the Campfire, spend earned AP, use available preparation items, and rest. Explore Zeke’s review loop, Gh0st’s endless-war route, and Orion’s shore route. Defeat their actual nightmare encounters. Return to the Campfire between fights as needed; both forward and reverse nightmare orders are tested.

2. Reassemble the party at the Campfire. The three early optional quests can then be completed by revisiting the personal nightmare branches and the Echo of the Mines.

3. Visit the Echo Patrol and evade the Manager. At the Memory Bridge, anchor Zeke, Gh0st, Orion, and Nova, then build the bridge. Hear the final banter on the span, rest there, and reach the Singularity through the Memory Threshold.

4. At the Memory Stair, refuse the revisions of Jed, the Astra, and the Foundry; then climb. Complete Ancestral Grave and The Last Scavenge during this ascent. Defeat Source Shadow at Memory Fragments and Memory Leak at the Spire Arena. Rest at the bridge span before the final encounters.

5. At The Center, confront Vale and finish both his dialogue and Nova’s answer. Defeat the Ascended: Soloist. Follow the north path through White Shore and Key Orbit to the Silence Pulpit for the Ascended: Silence. You can return to the bridge span to rest between these battles.

6. Return south to The Center and use the shared tuning focus. It remains locked until both forms are defeated. Match the focus’s slider targets and submit. Finish or skip the Final Note and epilogue cinematics to award 3,000 XP, complete MQ30, mark credits seen, and arrive in the New World. Saving during the pending ending and loading it resumes completion.

## Puzzles, choices, and recovery

The HR Record first removes the review’s authority while keeping the records as evidence. Its final choice is personal departure or freeing the workers; both grant Unshackled, and only the latter marks the worker-release outcome. Neither choice silently deletes the preserved evidence.

The final accessory is **Starborn**: +5 Strength, +5 Focus, +3 Luck, and +15 percentage points of critical chance. Equip it in an accessory slot. It does not convert basic attacks to Source damage. Source Balance grants Gh0st +5 flat damage reduction and 25% Source resistance; Unshackled grants Zeke +3 Agility/+2 Speed; Ancestral Grace starts Orion with three turns of Regen.

Local return shortcuts remain usable after their first trip, including saves with old completion receipts. Keep a separate save before the final tuning and ending scenes.

### The Campfire

#### The Campfire (`source_campfire`)

The song-fire burns again, rebuilt from blue waveforms on an island of memory. Three unstable paths pull away from the flame, each tuned to a missing crew member. Zeke's cubicles lie west, Gh0st's war corridor north, and Orion's shore east through Blue Ash Circle. The mine echo opens south. Each path can be retraced to this fire.

Exits: west → Infinite Cubicle, north → Endless War, south → Echo of the Mines, east → Blue Ash Circle.

Interactions: song-fire, memory oasis, campfire cookware.

#### Blue Ash Circle (`source_campfire_node_scale_01`)

Blue ash drifts around the Campfire in rings that never close. The open ring leaves space for each missing voice instead of smoothing them into one flame. The Campfire lies west and Orion's Silent Shore east; north, the ash path continues toward Three Dark Paths. Both shores lead back through this circle.

Exits: west → The Campfire, north → Three Dark Paths, east → Silent Shore.

Interactions: blue ash, open ring.

#### Three Dark Paths (`source_campfire_node_scale_02`)

Three dark paths pull away from the song-fire, each tuned to a different kind of fear. The fear tones are ugly, personal, and too specific for Vale to call noise.

Exits: south → Blue Ash Circle, north → Unshared Blanket.

Interactions: dark paths, fear tones.

#### Unshared Blanket (`source_campfire_node_scale_03`)

An unshared blanket lies beside the fire, folded with impossible neatness. The empty corner shows where the Source expects Nova to sit alone and call it strength.

Exits: south → Three Dark Paths, north → Key Ember.

Interactions: unshared blanket, empty corner.

#### Key Ember (`source_campfire_node_scale_04`)

A key ember turns inside the fire before the Key exists, waiting for the crew to come back with their jagged selves intact. The ember will not answer a single voice.

Exits: south → Unshared Blanket, north → Source Memory Shore.

Interactions: key ember, single voice.

#### Source Memory Shore (`source_campfire_node_scale_final`)

A memory shore curves around the Campfire, where tide marks from six worlds meet in blue ash. The tide marks and blue ash make the finale feel like the whole journey gathered in one place. A warm hearth memory chest glows softly in the blue ash. A one-way trail leads directly back to the entrance.

Exits: south → Key Ember.

Interactions: tide marks, blue ash, hearth memory chest, trail.
