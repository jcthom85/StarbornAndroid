# Starborn Observatory

Standalone PC readout for Starborn world and balance data. It does not modify the Android app.

Unified Observatory shell: `http://localhost:8765/starborn-observatory/observatory.html`

Product vision: `docs/OBSERVATORY_VISION.md`
Build backlog: `docs/BUILD_BACKLOG.md`
Implementation status: `docs/IMPLEMENTATION_STATUS.md`

Scenario Lens and relationship view: `http://localhost:8765/starborn-observatory/relationships.html`
Reference graph: `http://localhost:8765/starborn-observatory/graph.html`
Disposable state simulator: `http://localhost:8765/starborn-observatory/simulator.html`
Audio and cinematic lab: `http://localhost:8765/starborn-observatory/lab.html`
Story Moment Lens: `http://localhost:8765/starborn-observatory/moment.html`
Campaign flow: `http://localhost:8765/starborn-observatory/flow.html`
Quest stage consequences: `http://localhost:8765/starborn-observatory/quest-lens.html`
Quest context trace: `http://localhost:8765/starborn-observatory/context.html`
Quest stage state diff: `http://localhost:8765/starborn-observatory/diff.html`

Teaching console prototype: `http://localhost:8765/starborn-observatory/console.html`

Run from the repository root with `python -m http.server 8765`, then open `http://localhost:8765/starborn-observatory/`.
